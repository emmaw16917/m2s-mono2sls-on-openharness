M2S 流水线 v3

把"一个 LLM 主 Agent 从头到尾撑完整条流水线"，换成任务板加确定性调度器。每个任务启动一个独立的 worker，按工作包并行；需要来回讨论的问题进讨论室，不再全部经过主 Agent 转发。各模块做什么不变，变的是谁来调度、怎么通信。

  • 状态 M0 已完成（2026-10-30），下一步 M1
  • 底座 OpenHarness worker · Beads（br）任务板 · mcp_agent_mail
  • 依据 PIPELINE_V3_PLAN.md · 模块定义见 v2

三个核心变化

调度

确定性调度器代替主 Agent

派发、检查、回炉都由代码完成，状态全部记在任务板里，进程崩溃了可以重启接着跑。LLM 只在出现异常时按需启动，读一份案情材料后给出判断。

并行

按工作包拆任务

几个相关接口为一组，组成一个工作包，标注、测试设计、写代码都按包并行。分组规则由工具机械执行：运维类接口先分出、按亲和关系合并、按代码量控制大小。

通信与隔离

讨论室代替转发，权限真正执行

规格问题、分诊争议在讨论室里直接沟通，结论必须经工具写入。每个 worker 的读写范围由 OpenHarness 的权限强制执行，子 agent 也不能绕过。
